    System Information Inventory

    Audience: Students System: Windows / macOS / Linux Last reviewed: 2026-02-05

    Document your computer’s OS, CPU, RAM, Storage, and GPU using both GUI (settings/task manager/system info) and CLI (PowerShell or Terminal). Include screenshots and paste the command output as evidence.

    Good for
    Practicing real-world documentation: accurate specs, evidence, and repeatable commands.
    Be careful
    Remove/blur personal info in screenshots (device name, user folders, serial numbers) before publishing to GitHub.

    Purpose

    Create a clean “PC Snapshot” that someone else could use to understand your system hardware and verify it using command-line tools.

    How To

    Use PowerShell (Windows) or Terminal (macOS/Linux) to retrieve:

    • OS name, version, 32/64-bit
    • CPU model + cores/threads
    • RAM modules: size + speed
    • Storage: model + type (NVMe/SATA) + media type + size
    • GPU

    Windows — PowerShell commands

    OS (name/version/architecture) 
    Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsArchitecture
    CPU (model + cores/threads) 
    Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors
    RAM (modules size + speed) 
    Get-CimInstance Win32_PhysicalMemory | Select-Object Manufacturer, Speed, @{n="CapacityGB";e={[math]::Round($_.Capacity/1GB,2)}}
    Storage (model + size) 
    Get-PhysicalDisk | Select-Object FriendlyName, MediaType, BusType, @{n="SizeGB";e={[math]::Round($_.Size/1GB,2)}}
    GPU 
    Get-CimInstance Win32_VideoController | Select-Object Name

    macOS/Linux — Terminal commands

    macOS (OS + CPU + RAM) 
    system_profiler SPSoftwareDataType SPHardwareDataType
    macOS (Storage + GPU) 
    system_profiler SPStorageDataType SPDisplaysDataType
    Linux (common quick checks) 
    uname -a
lscpu
free -h
lsblk -o NAME,MODEL,SIZE,TYPE,MOUNTPOINT
lspci | grep -Ei "vga|3d|display"
